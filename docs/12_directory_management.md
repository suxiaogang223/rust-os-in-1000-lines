# 目录管理

## 概述

目录管理解决两件事：

1. 如何把“文件名 -> 目录项”的映射组织起来
2. 如何遍历目录并列出其中的条目

在 FAT 中，目录本质上就是“目录项（directory entry）的数组”。根目录与子目录在格式上类似，只是位置与大小的规则不同（FAT16 根目录固定区域；子目录在数据区用簇链表示）。

本仓库在 `src/fs/fat.rs` 中用 `root_directory: [FileInfo; ROOT_DIR_ENTRIES]` 表示根目录，并提供 `list_directory()` 打印目录项。

## FAT 目录项（简要）

FAT 目录项固定 32 字节，包含：

- 8.3 文件名
- 属性位（目录、只读、隐藏等）
- 时间戳（创建/修改等）
- 首簇号
- 文件大小

本教程的教学实现把其中最重要的字段抽到了 `FileInfo`。

## list_directory：遍历并打印

`list_directory()` 做了最小的“过滤 + 打印”：

- 跳过空条目（name[0] == 0）
- 跳过已删除条目（name[0] == 0xE5）
- 打印主名与扩展名（遇到空格做简单处理）
- 根据属性位打印 `DIR` 或 `FILE`

这非常适合作为验证点：

- 你能看到目录项是否被正确解析
- 文件名/大小/类型是否合理

## 练习：从“根目录数组”到“路径解析”

要支持真实的路径（如 `/TESTDIR/HELLO.TXT`），你需要实现：

- 路径分割与逐级查找（第 13 章的命令解析也会用到）
- 子目录的读取（根据目录条目的首簇号遍历簇链）
- `.`/`..` 等特殊目录项处理

这会把文件系统从“演示”推进到“可用”的关键一步。

## 小结

本章你应该理解：

- FAT 目录就是目录项数组，目录项里包含文件名/属性/首簇等信息
- 本仓库用固定根目录数组演示目录遍历与打印
- 支持路径解析与子目录读取是自然的下一步扩展方向
