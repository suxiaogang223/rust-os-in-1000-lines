# 贡献指南

欢迎对本项目提出改进建议与贡献代码/文档。下面是推荐的协作方式与本地验证流程。

## 贡献内容类型

- 文档：补充章节、修正文档与代码不一致、补充图示/练习
- 代码：修复 bug、补齐缺失机制（如上下文切换、virtio-blk、真实 FAT）
- 工具：改进构建脚本、调试体验、CI 等

## 开发约定（简要）

- Rust 2021，保持 `no_std` 友好
- 尽量缩小 `unsafe` 范围，并在必要处说明不变量
- 命名遵循：`snake_case`（函数/模块）、`CamelCase`（类型）、`SCREAMING_SNAKE_CASE`（常量）

## 本地验证

建议在提交前至少运行：

```bash
./test.sh
```

常用的快速循环：

```bash
make fmt
make check
make clippy
make run
```

文档预览：

```bash
cd docs
mdbook serve
```

## 提交说明（建议）

在 PR/提交说明中尽量包含：

- 改了什么、为什么改
- 相关 issue/讨论链接（如果有）
- 本地执行了哪些命令以及关键输出（尤其是文档/行为变化）

## 代码/文档一致性

本项目的教程章节会引用 `src/` 代码。若你修改了模块结构或关键 API，请同步更新：

- `docs/SUMMARY.md`（目录）
- 相关章节里的代码片段与说明

这样读者才能跟着教程一步步复现。
